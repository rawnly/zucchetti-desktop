## Design Context

### Users
A single employee on macOS who automatically archives monthly Zucchetti HR Progest payslips via `buste-paga-cf` (Cloudflare Worker + R2). They click the menu bar icon once a month to inspect and download payslips into a local folder—or trigger a manual fetch—and will later track and request PTO days from the same popover.

### Brand Personality
- **3-word personality:** Calm, precise, pro-tool.
- **Voice & tone:** Utility-first English copy; sentence case labels, concise metadata with middle-dot separators (`142 KB · Nov 27`), tabular numerals, zero marketing fluff.
- **Emotional goal:** Immediate clarity and quiet confidence—like a finely machined developer inspector.

### Aesthetic Direction
- **Visual tone:** Dark-only, near-black layered surfaces (Linear / Vercel / Raycast / agent-inspector feel). Elevation comes from 1px hairline borders and slight luminance steps, never heavy drop shadows. Chrome stays monochrome; saturated jewel tones appear strictly for data and status pills.
- **Exact palette:**
  - Popover background: `#121212`
  - Elevated card surface: `#1a1a1a`, hairline border `#2c2c2c`
  - Inset well / segmented track / input bg: `#141414`, border `#262626`
  - Selected segment pill: `#2a2a2a`, border `#383838`
  - Row hover tint: `rgba(255, 255, 255, 0.045)`
  - Hairline dividers: `#262626`
  - Text: primary `#f2f2f2`, secondary `#a8a8a8`, muted `#727272`
  - Primary CTA (inverted high-contrast capsule): `#f5f5f5` bg, `#111111` text
  - Ghost/outline capsule button: transparent/`#1a1a1a` bg, `1px` `#2e2e2e` border, `#e8e8e8` text
  - Status pills (capsule, tinted bg + same-hue text):
    - Synced / Saved: bg `#123a2a`, text `#4fd6a0`
    - Active / Syncing / Info: bg `#17325c`, text `#6ea8fe`
    - Error: bg `#3a1a24`, border `#7a2e44`, text `#ff6b81`
    - PTO legend accents: orange `#e8830c` (Vacation), blue `#6ea8fe` (Personal), teal `#2ec4b0` (Holiday)
- **Radii & rhythm:**
  - Popover width: `368px`, outer padding `12px`, `10px` vertical gaps
  - Cards: `14px` radius (`#1a1a1a` + `1px` `#2c2c2c`)
  - Segmented track: `10px` radius, selected segment `7px` radius
  - Pills & buttons: capsule (`Radius(999)`), circular icon buttons `28×28` with `1px` `#2e2e2e` border
  - Typography: system geometric sans (`15px` semibold title, `13px` medium row labels, `11.5px` muted metadata with `FontFeatures("tnum")`, `17px` medium tabular stat figures); monospace for filenames/URLs where helpful.
- **Anti-references:** Embedded PDF viewers, heavy shadows, light-gray generic tables, noisy color accents on chrome, modal settings windows.

### Design Principles
1. **Monochrome chrome, jewel-toned data:** Reserve green, blue, pink-red, orange, and teal strictly for sync/saved status pills, active progress, errors, and PTO category swatches.
2. **Hairline elevation:** Separate popover bg (`#121212`), cards (`#1a1a1a`), and inset wells (`#141414`) with crisp `1px` hairlines (`#262626`–`#2c2c2c`).
3. **Tabular precision:** Every count, file size, date, and stat figure uses `FontFeatures("tnum")` and concise middle-dot separators.
4. **One-click utility:** Clicking an unsaved payslip downloads it into the chosen folder; clicking a saved payslip reveals/opens it; settings and errors live inline inside the popover.
5. **Expandable by construction:** Top segmented switcher (`Payslips` | `PTO`) with the same card + color-swatch legend language ready for the upcoming Zucchetti PTO workflow.
